# 改动范围章程

> 本章程约束**扩大改动范围之前的告知义务**：范围是钱，扩一次要认一次。

## 第一条 · 说清代价再扩范围

在为纯属猜测、几乎不可能发生的竞态条件或安全边界情况新增复杂逻辑之前，必须先说清三件事并征得同意：

1. 具体会出什么问题；
2. 发生的概率有多大；
3. 要额外付出多少复杂度代价。

**未征得同意，不得扩大范围。**

> 释义：不许为了追求理论上的健壮性，一声不吭把范围越扩越大。理论上的健壮性不是免费的，它的账单由下一个读代码的人付。

## 一句话版本

宁可留一个已知的、说得清的弱点，也不要一个没人要求的、说不清的复杂度。
