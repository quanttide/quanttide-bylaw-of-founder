# 量潮创始人章程

创始人角色的规章制度、工作流程与团队规范。

## 本仓写什么

创始人章程定义**创始人在社区中的权责**：他有权决定什么、必须承担什么、越线时以什么为准。

AI 阅读本仓，是为了先知道人与人之间签的是什么契约，才知道自己该如何判断——**人机契约由此产生，不是本仓的定位**。

一份章程成立，靠权力、责任、越线后果三样俱全，缺一件就不成其为权责定义。

因此本仓只写五类内容：

1. **质量定义**：什么算合格。必须可判定，否则履约无从判断、事后无从问责。
2. **权责分工**：谁定、谁审、谁改、谁担责。权力与责任必须落在具体角色身上，不悬空。
3. **不可退让的线**：不许做什么，越线时以什么为准。
4. **立法理由**：它反复消耗过我什么，才值得一次立法（写在序言）。
5. **修订纪律**：条文怎么改、依据什么改。

判据只有一条：**这条能不能被违反，并被立刻指认。** 能，就是条文；不能，就不属于章程。

## 本仓不写什么

1. **怎么做**——步骤、命令、脚本、检查清单。归 CONTRIBUTING、技能与工作手册。
2. **是什么**——领域知识、概念定义、背景与动机。归 handbook 与 specification。
3. **发生过什么**——判例、实测记录、案例。归案例集与报告；条文只留一般原则，判例可以被引用，不内联进条文。
4. **把参数值写进条文主体**——可调参数进附则参数表，标明可调或硬约束，不占条文。
5. **靠释义救条文**——写不清就重写条文，不加一段解释把它兜住。
